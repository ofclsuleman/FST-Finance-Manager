                    # FST Finance - Setup Instructions

Thank you for downloading FST Finance! Follow these quick steps to get started:

1. UNZIP THE FILE
   - Right-click the downloaded zip archive (FST_Finance.zip).
   - Select "Extract All..." and choose your desired folder location.

2. CREATE SHORTCUT
   - Open the extracted folder.
   - Double-click "create_shortcut.bat" to automatically create a desktop 
     shortcut for easy access.

3. ENJOY THE PROGRAM
   - Double-click the "FST Finance" icon on your Desktop to launch the application.
